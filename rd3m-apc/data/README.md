# RD3M APC data

The files in this directory are generated by `../prepare-data.R` from the Bondora
snapshot used by the credit-vintage article at jkunst.com. The visualization
should only read these static outputs; it should not recompute the APC
construction in the browser.

## Definition

For a loan alive at the start of age `a`, RD3M is one when the loan defaults at
age `a`, `a + 1`, or `a + 2`, and zero otherwise. A zero outcome is used only
when all three months are observable. If a loan defaults inside the three-month
window, the outcome is already known and the observation can end at that default.

The analysis follows origination cohorts from January 2018 through December 2022
and starts three-month windows only through age 34, so every non-default window
fits inside the first 36 months of loan life.

At cell level:

```text
RD3M = defaults in [a, a + 2] / loans at risk at age a with known 3-month outcome
```

The sequential APC construction mirrors the methodology in the source article:

```text
RD3M
  -> add-half correction
  -> logit
  -> global weighted mean
  -> AGE
  -> COHORT
  -> PERIOD
  -> residual
  -> inverse logit / RD3M contributions
```

All APC means use `loans_at_risk` as weights. The order is intentional: this is a
sequential descriptive decomposition, so COHORT is estimated after AGE and PERIOD
after AGE + COHORT.

## Files

- `rd3m-data.json`: compact payload for the interactive story. It contains a
  didactic 5-period x 5-age example, the full AGE/COHORT/PERIOD effects, metadata,
  and the portfolio reconstruction.
- `rd3m-cells.csv`: complete cell-level output for inspection and debugging.
- `rd3m-portfolio.csv`: period-level RD3M and its additive risk-scale components.

The didactic example uses five calendar periods from February through June 2020 at
ages 1 to 5. Its 25 cohort-age cells span the necessary origination cohorts, and
its APC decomposition is recomputed only on those visible cells so every weighted
average shown in the visual explanation can be reproduced exactly from what is on
screen. The portfolio chart uses the decomposition estimated on the full analysis
table.

`prepare-data.R` checks that the logit reconstruction, cell-level RD3M
reconstruction, and period-level portfolio reconstruction close to numerical
precision before writing any outputs.
